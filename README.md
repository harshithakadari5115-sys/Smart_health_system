# HealthFlow - AI-Enabled Unified Patient Health Record System

## 🏥 Project Overview

HealthFlow is an integrated AI-enabled healthcare platform that connects patients, doctors, laboratories, pharmacies, and hospital administrators through a single unified system.

### Key Features
- **Unified Digital Health Record**: Unique Health ID linking all patient medical information
- **Smart OPD Management**: Real-time token tracking with AI-powered waiting time prediction
- **Real-Time Laboratory Tracking**: Live sample processing status updates
- **AI Medical Report Assistant**: OCR/NLP-powered report analysis and terminology simplification
- **Doctor Dashboard**: Centralized access to complete patient history
- **Emergency Information Access**: Quick QR-based critical information retrieval
- **Hospital Admin Dashboard**: Comprehensive analytics and resource monitoring
